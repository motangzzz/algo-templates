# 算法竞赛模板

个人算法竞赛常用模板，C++ 实现。

## 模板列表

| 文件 | 说明 |
|------|------|
| `快速幂.cpp` | 快速幂（含取模） |
| `并查集.cpp` | 并查集（路径压缩 + 按大小合并） |
| `线段树.cpp` | 线段树（区间和查询） |
| `树状数组（一维）.cpp` | 一维树状数组 |
| `树状数组（二维）.cpp` | 二维树状数组 |
| `st表.cpp` | Sparse Table（RMQ） |
| `单调栈.cpp` | 单调栈 |
| `前缀树(trie)类实现.cpp` | Trie 前缀树（类封装） |
| `倍增法求lca.cpp` | 倍增法求 LCA |
| `拓展欧几里得.cpp` | 扩展欧几里得算法 |
| `01背包.cpp` | 01 背包 |
| `完全背包.cpp` | 完全背包 |

## 使用

```cpp
#include<bits/stdc++.h>
using namespace std;
```

每个模板独立成文件，可直接复制使用。
